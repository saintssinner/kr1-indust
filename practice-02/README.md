## 4. Модель данных и функции

Поля задачи: id (безопасное целое > 0), title (строка 1-100 после trim), completed (boolean), priority ("low", "medium", "high").
Валидация: Строгие проверки типов. Для id используется Number.isSafeInteger(id) && id > 0.
Назначение файлов:

task-service.js - чистая логика, возвращает { ok: true, task/tasks } или { ok: false, error }.
data.js - статические наборы данных.
main.js - демонстрационный сценарий с выводом в консоль.
Почему id не равен индексу: Индекс меняется при удалении/добавлении элементов. id- это постоянный идентификатор, не зависящий от позиции в массиве.
Почему getTaskStats возвращает число: Функция должна возвращать сырые данные для дальнейших вычислений. Форматирование (округление через toFixed(1)) - задача слоя представления (main.js).
Какие объекты копируются при изменении задачи: При изменении completed или title создаётся новая копия самого изменяемого объекта через { ...task, completed } или { ...task, title }. Остальные задачи в массиве не копируются, так как они не меняются.
