## 2. Результаты экспериментов с DOM (Задание 1)

1. **Поиск отсутствующего элемента и пустой коллекции:** Метод `querySelector` возвращает `null` (попытка обращения к его свойствам без предварительной проверки приведет к ошибке). В то же время `querySelectorAll` возвращает пустую коллекцию `NodeList` с длиной `0`, с которой безопасно работать в цикле.
2. **Чтение `dataset.taskId` у кнопки:** До преобразования значение из дата-атрибута имеет строковый тип (например, `"23"`). После вызова функции `Number()` значение корректно преобразуется в числовой тип (`23`).
3. **Поведение `querySelectorAll` при повторном нажатии «Добавить запись»:** Полученная ранее коллекция является статической и не обновляется автоматически при изменениях DOM-дерева. Для получения актуальных данных требуется выполнять новый запрос.
4. **Вывод текста со спецсимволами («Изменить заголовок»):** Использование свойства `textContent` выводит строку «как есть» вместе с угловыми скобками и тегами, отображая их как обычный текст и не создавая реальных HTML-элементов внутри структуры.
5. **Исследование журнала событий (фазы и свойства):** При клике по вложенному тегу `span` событие проходит фазу погружения, достигает целевого элемента (`target`), а затем поднимается вверх по цепочке предков (всплытие), где срабатывает делегированный обработчик на контейнере (`currentTarget`).

## 3. Архитектура и модули
- **`src/data.js`**: Хранит общие тестовые данные и набор задач для Варианта № 7.
- **`src/task-service.js`**: Содержит чистую прикладную логику (поиск, CRUD-операции, статистику) из ПР2 без использования DOM.
- **`src/task-selectors.js`**: Отвечает за чистую фильтрацию задач по статусу (`all`, `pending`, `completed`) без мутации исходных массивов.
- **`src/task-view.js`**: Инкапсулирует создание DOM-элементов карточек, рендеринг списка через безопасный `textContent`, обновление сводки и пустых состояний.
- **`src/main.js`**: Управляет состоянием приложения (`currentTasks`, `currentFilter`), делегированием событий клика и связкой сервисов с отрисовкой.
