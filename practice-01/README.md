## Доп. задание А
Файл: `progress-input.js`. Вход приходит строками.  
Порядок: `typeof` -> `trim()` -> проверка на пустоту -> `Number()` -> `Number.isInteger()` -> ограничения задания 3.  

**Почему недостаточно `Number()` и проверки "не отрицательно":**
- `Number("")` и `Number("   ")` дают `0` - пустой ввод прошёл бы как «0 задач»;  
- `Number("abc")` даёт `NaN`, а `NaN < 0` - false;  
- `Number("2.5")` - дробное, `Number("Infinity")` - не целое;  
- `null` и `undefined` не имеют `.trim()`.
